Connect a free Spotify app so Spotify links go straight to the matched album instead of a search page. Create one at developer.spotify.com/dashboard (Web API, no redirect URI needed) and paste the Client ID and Client Secret below. Stored only in this browser.

Last.fm Scrobbling

Scrobbles YouTube-sourced plays to Last.fm — Spotify plays already scrobble on their own via Last.fm's own Spotify connection, so this only ever covers what that can't see. Create a free API application at last.fm/api/account/create (any name/description; the Callback URL field can be left blank — this doesn't use it) and paste the API Key and Shared Secret below. Stored only in this browser.

Connect your account

Save your API Key/Secret above first, then connect the specific Last.fm account to scrobble to.

Discogs API

Used for the "⤓ Discogs" genre lookup in Edit details. Discogs requires a personal access token for search — generate a free one at discogs.com/settings/developers (Generate new token; no OAuth app registration needed). Stored only in this browser.

YouTube API

Used for the "Match" button on the tracklist builder and "Edit track properties…" to search YouTube for real candidate videos instead of opening a search tab. Get a free API key: Google Cloud Console → create/select a project → enable "YouTube Data API v3" → Credentials → Create API key. The free tier is limited (100 searches/day), so matching only runs when you click it, never automatically. Stored only in this browser.

        Genre Taxonomy
        
    
        
      
        Set which broader genre each one falls under — e.g. Shoegaze under Alternative Rock, itself under Rock. A genre can have more than one parent too (Glam Punk under both Punk Rock and Glam Rock — separate multiple with commas, same as the Genre/Secondary Genre fields elsewhere). Filtering by a parent genre then also surfaces everything beneath it in the hierarchy, and the left panel's Genres list shows the tree with counts that include the whole branch. Leave a genre's field blank for top-level (no parent). Saved to your account, so every browser you sign in on gets it (see Back up, move and sync).
        
      
        
        
        Back up, move and sync
        
        
        Your taxonomy is saved to your account (the spreadsheet) so every browser you sign in on gets it. Export it to keep a copy, or to carry it to another device; import one to add to this one or replace it.
